# Visual sources and how to read them

An illustration should answer a question that is harder to answer from prose alone. Commands and short terminal results are text so you can select, search and compare them. Expected-output panels have a separate colour and label and no Copy button.

## Concept diagrams

The robotics feedback loop, software stack, ROS communication patterns, middleware boundaries, callback timeline, QoS comparisons, coordinate geometry and camera geometry are original course diagrams. Their captions explain what to trace or compare; they are models of a system, not screenshots of a running experiment. Technical references accompany the corresponding lesson. Original course diagrams are shared under the course's **CC BY 4.0** terms; retain the course attribution when reusing them.

## Windows launch illustration

The three-method Ubuntu launch image in lecture 00 is an **AI-generated simulation**, with explanatory callouts outside the application panels. It is not a captured Windows session; theme, icons, profile names and menu arrangement can differ on your machine. The methods themselves are supported by [Microsoft's WSL command documentation](https://learn.microsoft.com/en-us/windows/wsl/basic-commands) and [Windows Terminal profiles](https://learn.microsoft.com/en-us/windows/terminal/customize-settings/profile-general).

Use the copyable text command in the lesson when typing. Windows and Ubuntu interface marks identify the software being taught; they do not indicate endorsement.
